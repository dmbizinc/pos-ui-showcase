# POS UI Showcase

Static gallery of design mockups for a restaurant POS platform (fictional Cypress & Coast demo company).

The site is published with GitHub Pages from `main`. Everything in the mockups is fictional; they are design/review material, not a shipping product.

## Updating
Replace `index.html` and the numbered image folders (`01-…`–`16-…`), open a pull request, merge to `main` — the workflow redeploys automatically.
